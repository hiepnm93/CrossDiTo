# CrossDiTo 1.5.2

CrossDiTo 1.5.2 rebases the fork onto **CrossInk 1.6.0**. All upstream 1.5.1 and 1.6.0 features and fixes are inherited; CrossDiTo-specific behavior was re-verified against the new base.

## Verified firmware

- File: `CrossDiTo-x4-pro-v1.5.2.bin`
- Size: 6,073,888 bytes
- SHA-256: `a505f4aa740928cd61abc2474eb35674182f97b180010c5208327cac5de4950f`
- OTA partition headroom: 479,712 bytes
- Hardware verification: **pending** — flash to an Xteink X4 Pro, read back in full, and match byte-for-byte before publishing as stable, following the same process as the [1.5.1 release](v1.5.1.md).
- Source verification: a clean X4 Pro build reproduces the verified image's code layout, section sizes, and complete defined-symbol layout. Build timestamps and generated gzip timestamps make independently compiled binary hashes differ.

## What changed relative to CrossDiTo 1.5.1

- The fork now tracks upstream CrossInk 1.6.0, so upstream features such as X4 Classic support, the full X4 Pro touch menu, decimal book-progress precision, stable-page and keypad jumps, file rename in the browser, per-build UI language selection, and publisher page numbers arrive automatically instead of being fork-maintained.
- The 1.5.1 engineering internals that duplicated upstream 1.6 systems were removed: the compiled chapter-event cache, retained-next-page prefetch, whole-book pagination display, and the 1.5.0-era reader pipelines. The performance and battery estimates published in the [1.5.1 release notes](v1.5.1.md) no longer apply; re-engineering these optimizations on the new base is tracked as follow-up work.
- The build-level X4 Pro power policy from 1.5.1 is carried over: dynamic CPU frequency scaling, tickless light sleep, USB-plug light-sleep wake tuning, and GT911 touch-wake interrupt gating.
- Frontlight behavior follows upstream CrossInk; the CrossDiTo 10-bit low-brightness PWM experiment was intentionally not carried over.
- The development device simulator now builds and runs natively on Windows (MinGW/MSYS2) and Linux hosts in addition to macOS, so firmware work no longer requires WSL or a Mac.

## Complete CrossDiTo 1.5.2 changelog

### Added

- CrossInk 1.5.1 / 1.6.0 upstream features: X4 Classic support, full X4 Pro touch menu, decimal book-progress precision, stable-page and keypad jumps, file rename in the browser, per-build UI language selection, publisher page numbers, and all upstream stability fixes.
- Return to Previous Reading Position after deliberate reader-menu jumps (one-shot, back to the page you jumped from).
- Build-level X4 Pro power policy carried over from CrossDiTo 1.5.1: dynamic CPU frequency scaling, tickless light sleep, USB-plug light-sleep wake tuning, and GT911 touch-wake interrupt gating.
- The development device simulator now runs natively on Windows (MinGW/MSYS2) and Linux hosts alongside macOS; Windows relies on the reapplyable `scripts/patch_simulator_libdeps_windows.py` libdeps patch.

### Changed

- Frontlight behavior now follows upstream CrossInk (the CrossDiTo 10-bit low-brightness PWM experiment is intentionally not carried over).
- KOReader Sync entry opens KOReader settings first when no credentials are configured (matches upstream behavior).
- i18n catalogs merge CrossDiTo strings with all upstream 1.6 languages.

### Removed

- CrossDiTo 1.5.1 internals that duplicated upstream 1.6 systems: compiled chapter-event cache, retained-next-page prefetch, whole-book pagination display, and the 1.5.0-era reader pipelines. These need re-engineering on the new base and are tracked as follow-up work.

### Fixed

- The native simulator now builds on Linux hosts: the narrowing suppression flag gained its GCC spelling alongside the Clang one, a new `scripts/sim_native_host_compat.py` pre-script pins C libdeps to gnu17 (GCC 15 defaults to C23, breaking QRCode's own `bool` typedef) and links libcrypto for the Linux MD5Builder, and stale Windows-patched simulator libdeps must be re-downloaded (`rm -rf .pio/libdeps/x4-pro-simulator`).

The complete inherited CrossInk/CrossPoint history is preserved in [CHANGELOG.md](../../CHANGELOG.md).
